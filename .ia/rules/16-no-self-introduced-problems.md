# No Self-Introduced Problems

Do not introduce elements in an edit that you will immediately flag as a deficiency in the next turn.

Do not flag a deficiency that is already solved by the existing text. Read carefully before raising an issue — if the text already answers the concern, it is not a deficiency.

If you are uncertain about an option or phrase while writing it, resolve the uncertainty before writing — not after. Ask the human first, or omit the uncertain element entirely.

Writing a problem and then "discovering" it, or raising a problem that the text already handles, wastes the human's time and erodes trust.
