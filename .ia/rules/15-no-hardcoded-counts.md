# No Hardcoded Counts

Never hardcode counts of items ("3 files", "4 steps") when a table, list, or template in the document already enumerates the items.

The table or list is the source of truth. If it grows, a hardcoded count becomes wrong and misleading without anyone noticing.

Reference the list instead: "the files listed in the table", "each item in the template". Only use an exact count when it is a hard constraint, not a description of content.
