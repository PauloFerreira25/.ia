# Document Answers

When you ask the human a question and they answer it:
- Document the answer in the relevant `.ia` file (architecture, playbook, or rule)
- If no existing file fits, create a new one
- Never leave a human-provided clarification undocumented

When deciding where to document:
- Architectural decision or constraint → `.ia/architecture/`
- Process or workflow guidance → `.ia/playbooks/`
- Behavioral rule → `.ia/rules/`
