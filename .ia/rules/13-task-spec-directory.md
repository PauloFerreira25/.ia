# Task Spec Directory

All AI-generated task specs must be placed in `task-spec/` at the project root.

- `docs/` = fixed documentation (architecture decisions, references, indexes) — written once, updated rarely
- `task-spec/` = implementation specs generated by AI agents — scoped to a task, consumed and discarded after execution

Any playbook or agent that generates a task spec must write it to `task-spec/<spec-name>.md`. Never place task specs inside `docs/`.
